- 内容详情目前以结构化数据和链接为主，后续再接文章、音频、项目详情和可试玩页面。

## 下一步建议

1. 抽取固定角色为独立 GLB/组件，并建立跨场景相同的锚点、镜头和灯光规范。
2. 依次接入工作、游戏、出发场景，每个场景复用同一套 `SceneShell`、热点和内容面板。
3. 将热点位置从百分比升级为场景锚点映射，确保不同相机比例下仍精确贴合物件。
4. 为场景切换加入“退场物件收拢 → 环境替换 → 新物件出现”的状态机动画。
5. 在真实内容 URL 和公开边界确认后，补齐项目、文章、播客、旅行和 AI 分身入口。
