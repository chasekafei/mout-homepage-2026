# MouT.me 视觉方案 2：创作场景重建

更新日期：2026-09-05

这一版以视觉方案 1 的创作概念图为构图参照，重新导出了独立的 Blender 资产 `create-scene-v2.glb`，并重新校准了网页相机与热点。

## 对照方案 1 的执行结果

- 保留黑色工作台、固定坐姿体素角色、报纸、CrossPod 麦克风/波形、独立产品原型仓、三阶魔方和两只猫。
- 通过水平镜像把角色放到舞台左侧、产品入口展开到右侧，恢复概念图的阅读顺序。
- 移除 Blender 内置场景标题、背景板和调试 marker，避免模型内部文字镜像或辅助点覆盖内容。
- 三阶魔方从 GLB 的 `rubik_root` 独立出来，网页中持续缓慢旋转。
- 热点直接使用 GLB 坐标锚点，不再用屏幕百分比定位，因此相机和视口改变时不会漂移。

## 与生成概念图的差异

- 概念图包含高精度体素材质、复杂柔光和大量细节；当前资产使用可维护的低多边形几何，优先保证可加载、可交互和跨场景复用。
- 角色面部使用黑发、眼镜、衣服标记和轮廓表达，没有尝试生成不可控的面部细节。
- 文字、标题和内容信息由网页 HTML 渲染，Blender 内的中文/英文文字只作为辅助参考并默认隐藏。
- 物件的打开动作当前进入内容面板，下一阶段会继续实现从物件位置生长出的内容过渡。

## 当前资产

- Blender 脚本：`tools/blender/build_create_scene_v2.py`
- Blender 源文件：`public/assets/create-scene-v2.blend`
- 网页资产：`public/assets/create-scene-v2.glb`
- 资产说明：`docs/create-scene-v2.md`

## 下一轮精修方向

1. 将角色和桌面拆成独立可复用的 GLB 模块，建立所有场景共享的固定锚点。
2. 继续调整桌面物件的遮挡关系，让报纸、波形、产品仓和魔方在同一视角下都保持独立轮廓。
3. 为不同状态建立不同环境色和材质方案，保留黄色作为 `MouT.me` 的识别色。
4. 继续对照方案 1 概念图，完善灯光、软阴影、AO 和物件细节。
