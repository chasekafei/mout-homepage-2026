# 出发场景建模设计要素和构图

下面按**驾驶员视角**描述：画面中心是车辆行驶方向，左/右均以车内视角为准。建模时建议先固定车外道路、地平线和主地标，再补充两侧景物。

## 统一构图规则

- **前景**：车头外的道路、路肩、护栏或水面。
- **中景**：主地标、道路两侧的树木、建筑、标牌。
- **远景**：城市天际线、山体、海岸线或天空。
- **主地标**：尽量放在画面中央或中央偏一侧，不能被路牌和树木遮住。
- **车外视线**：道路从画面底部中央向远处收束，形成明显的透视线。
- **地点牌**：统一放在道路右侧或右前方，作为系列固定视觉符号。
- **外景风格**：体素化、块面化，但每个地点的地理特征要靠主地标和环境类型区分。

# 1. 巴统 Batumi

### 车外内容

- 黑海海滨大道
- 阿里和尼诺雕像
- 巴统灯塔
- 海水、海岸护栏和滨海步道
- 棕榈树
- 巴统现代高楼和装饰性城市建筑
- 黄色“巴统·出发”路牌

### 构图关系

- **前景**：车辆在沿海公路上行驶，深灰色道路从底部中央向前延伸。
- **左侧中景**：黑海，水面占据左侧较大区域，远处可以有小船或海岸线。
- **中央远景**：阿里和尼诺雕像作为第一主地标，位于海滨步道附近，最好放在道路正前方略偏左。
- **右侧中景**：棕榈树、滨海建筑和巴统城市街区。
- **右侧远景**：巴统灯塔，体量小于阿里和尼诺，但要能看见白色塔身和顶部结构。
- **天空**：明亮蓝天和少量体素云。

### 建模重点

巴统的辨识度主要来自：

> 黑海 + 海滨大道 + 阿里和尼诺 + 棕榈树 + 巴统灯塔。

阿里和尼诺不要放在城市深处，应当明确处于海边开放空间。

# 2. 名古屋 Nagoya

### 车外内容

- 银灰色 MIRAI TOWER
- 久屋大通公园
- 长条形浅水池或喷雾水景
- 名古屋城市建筑
- 哈尔移动城堡元素
- 天空之城巨型机器人
- 小型无脸男元素
- 金泽、高山、下吕的辅助旅行线索
- 塔身竖向文字：`Aichi-Nagoya 2026`
- 黄色“名古屋·出发”路牌

### 构图关系

- **前景**：道路从底部中央向前延伸，和久屋大通的水景方向一致。
- **中央远景**：MIRAI TOWER 位于画面正中，是绝对主地标。
- **中央下方**：水池或喷雾区域形成一条指向塔底的透视线。
- **左侧中景**：公园树木、步道和部分城市建筑。
- **右侧中景**：商业楼、绿化和次级公共空间。
- **左侧或右侧远景**：哈尔移动城堡、巨型机器人等吉卜力公园元素，作为次级景物，不要抢过塔。
- **更远处**：金泽町屋、高山木造街道、下吕温泉蒸汽可以做成沿途式小型场景，但不建议并列成三个完整景区。
- **塔身**：银灰色钢架结构，不能做成红色东京塔。文字竖向布置在塔身中央或观景台下方。

### 建模重点

名古屋的识别顺序应是：

> 银灰色 MIRAI TOWER → 久屋大通水景 → 日本城市公园 → 吉卜力元素。

金泽、高山、下吕只负责表达“这是一段日本旅行路线”，不应成为主视觉。

# 3. 第比利斯 Tbilisi

### 车外内容

- 圣三一大教堂
- 第比利斯山坡城市
- 老城木质阳台
- 涂鸦墙和旧建筑
- 石砌街道或坡道
- 远处山地
- 黄色“第比利斯·出发”路牌

### 构图关系

- **前景**：道路略带坡度，从底部中央向上延伸。
- **左侧中景**：老城街道、石墙、彩色涂鸦和不规则建筑。
- **中央远景**：圣三一大教堂位于山坡或城市高处，金色穹顶要清楚可见。
- **右侧中景**：带木质阳台的老城区建筑，楼体高低错落。
- **远景**：第比利斯山坡和密集城市建筑。
- **天空**：暖色阳光或清澈高加索天空。

### 建模重点

圣三一教堂应该在城市高处，不能和道路处于同一平面。第比利斯的特色不是单独一座教堂，而是：

> 山地城市 + 老城阳台 + 涂鸦 + 教堂穹顶。

# 4. 赛里木湖 Sayram Lake

### 车外内容

- 赛里木湖
- 天山雪山
- 高山草原
- 湖边公路
- 牧马、牛羊
- 白色毡房
- 野花和草甸
- 黄色“赛里木湖·出发”路牌

### 构图关系

- **前景**：沿湖公路从底部中央向前延伸，可以有黄色道路标线和粗糙路肩。
- **左侧中景**：赛里木湖大面积展开，湖岸线向远处收束。
- **中央远景**：雪山横向铺开，形成连续山脉背景。
- **右侧中景**：金绿色草原、毡房和几匹马。 
- **道路一侧**：可以加入木质护栏、观景台或路边石块。
- **天空**：高海拔地区的深蓝天空、白云和强烈日光。

### 建模重点

不能只做普通湖泊。必须同时出现：

> 高山湖泊 + 雪山 + 草原 + 牧马/毡房。

湖水应该占画面较大面积，雪山在湖面上方形成完整背景带。

# 5. 多哈 Doha

### 车外内容

- 伊斯兰艺术博物馆
- 海上热气球
- 海上落日
- “饺子皮”雕塑
- 卢赛尔体育馆
- 多哈滨海大道
- 棕榈树、海湾水面和现代天际线
- 黄色“多哈·出发”路牌

### 构图关系

- **前景**：滨海大道或海湾边道路，路面从底部中央向前延伸。
- **左侧中景**：海湾水面，落日靠近左侧或中央偏左的地平线。
- **中央远景**：伊斯兰艺术博物馆作为主要建筑，放在海边或水面尽头，使用层叠的几何体块。
- **海面上方**：热气球数量不宜太多，放大为两到三个明显物体，位于落日附近。
- **右侧中景**：白色“饺子皮”雕塑，放在滨海步道或广场边，体量中等。
- **右侧远景**：卢赛尔体育馆或现代体育建筑，用作城市现代化线索。
- **更远处**：多哈高楼天际线和海湾雾气。

### 建模重点

多哈不能只做沙漠和摩天楼，核心识别组合是：

> 伊斯兰艺术博物馆 + 海湾夕阳 + 放大的海上热气球 + “饺子皮”雕塑。

热气球要明显放大，否则在车内视角中会变成无法辨认的小点。

# 6. 北海道 Hokkaido

### 车外内容

- 登别地狱谷
- 硫磺蒸汽
- 火山岩地貌
- 针叶林
- 温泉旅馆和灯笼
- 雪山或积雪
- 可以加入函馆百万夜景作为远景线索
- 黄色“北海道·出发”路牌

### 构图关系

- **前景**：道路穿过登别温泉区域，路面两侧有积雪和黑色火山岩。
- **左侧中景**：地狱谷岩壁、硫磺蒸汽和裸露的火山地表。
- **中央远景**：道路通向温泉区域或山谷深处。
- **右侧中景**：针叶林、温泉旅馆、木质建筑和暖黄色灯笼。
- **远景**：雪山或雾气笼罩的山谷。
- **辅助元素**：可以在远处山坡或天空中加入极小的函馆夜景式城市灯光，但不建议真正变成夜景。

### 建模重点

北海道这一张优先表达：

> 登别地狱谷 + 硫磺蒸汽 + 雪地森林 + 温泉旅馆。

函馆百万夜景和登别不是同一地点，建模时最好只作为远处小型旅行记忆符号，不要与地狱谷并列成两个完整场景。

# 7. 福冈 Fukuoka

### 车外内容

- 福冈塔
- 太宰府天满宫
- 红色鸟居
- 神社屋顶
- 梅花树
- 福冈城市建筑
- 黄色“福冈·出发”路牌

### 构图关系

- **前景**：城市道路，从底部中央通向远处。
- **中央或左侧远景**：福冈塔，细长高耸，作为现代城市地标。
- **右侧中景**：太宰府天满宫风格的红色鸟居、木质建筑和瓦顶。
- **道路两侧**：樱花或梅花树、日式围墙和小型石灯笼。
- **远景**：福冈现代高楼和蓝色海岸线。
- **标志关系**：鸟居不能遮住福冈塔，两个地标应当形成“现代城市 + 传统神社”的左右组合。

### 建模重点

福冈的识别组合是：

> 福冈塔 + 太宰府鸟居 + 梅花 + 现代城市。

福冈塔应该保持细长、现代、偏银灰或蓝色的外观，不要做成普通电视塔。

# 8. 大连 Dalian

### 车外内容

- 星海广场
- 海岸线
- 大量海鸥
- 广场环形或放射状结构
- 大连城市建筑
- 海鲜餐饮线索
- 海胆饭、海肠捞饭等可以做成路边餐饮招牌或车外小摊的图形暗示
- 黄色“大连·出发”路牌

### 构图关系

- **前景**：宽阔道路或星海广场边缘，空间要比普通城市道路开阔。
- **左侧中景**：大面积海面和海岸护栏。
- **中央远景**：星海广场的环形广场结构、纪念性雕塑或滨海建筑。
- **天空**：大量海鸥从左向右或从远处飞来，形成动态识别元素。
- **右侧中景**：海鲜摊、餐饮店或带海洋元素的城市建筑。
- **远景**：大连滨海天际线、桥梁或海湾轮廓。

### 建模重点

大连最重要的不是普通海景，而是：

> 星海广场的超大尺度 + 海鸥群 + 海岸线。

广场需要比道路宽很多，不能只做成一条普通滨海公路。

# 9. 长沙 Changsha

### 车外内容

- 中南大学体育馆
- 湘江
- 橘子洲或洲头轮廓
- 长沙城市高楼
- 夜市 / 小吃街元素
- 橘红色城市灯光
- 黄色“长沙·出发”路牌

### 构图关系
 - **前景**：城市道路从底部中央向前，周围是长沙城区。
- **左侧中景**：中南大学体育馆，作为个人经历主地标，体量要明确。
- **右侧中景**：湘江或江岸道路，配合树木和滨水栏杆。
- **中央远景**：橘子洲或江中岛屿轮廓。
- **右侧远景**：长沙高楼、霓虹招牌和城市建筑。
- **辅助元素**：路边小吃摊、红色灯笼、热闹街区，但不应该盖住体育馆。
- **天空**：可用夕阳或暖色日光，突出长沙湿热、活跃的城市氛围。

### 建模重点

长沙目前没有特别明确的个人地标组合，所以构图优先级应该是：

> 中南大学体育馆 → 湘江 → 长沙城市高楼 → 长沙街头烟火气。

中南大学体育馆应该放在左侧或左前方，成为画面中最明确的建筑，而不是只在远处出现一个普通体育场。

# 10. 哈尔滨 Harbin

### 车外内容

- 冰雪大世界摩天轮
- 温度计小钟楼
- 网红大雪人
- 彩色冰雕城堡
- 蓝紫色冰雪灯光
- 积雪道路
- 穿冬装的游客
- 黄色“哈尔滨·出发”路牌

### 构图关系

- **前景**：积雪道路或冰面，从底部中央延伸进入冰雪大世界。
- **左侧远景**：巨大的白色摩天轮，轮心带雪花形灯光结构。
- **中央中景**：蓝色冰制温度计小钟楼，钟面和温度刻度清楚可见。
- **右侧中景**：网红大雪人，红帽、深红围巾和红色爱心要明确。
- **四周**：冰雕城堡、冰塔、彩色灯光和小型游客剪影。
- **天空**：深蓝色冬夜天空，配合青色、紫色和白色灯光。

### 建模重点

哈尔滨这一张的三个地标应当分工明确：

- 摩天轮：左侧，高大、负责远景轮廓
- 温度计钟楼：中央，负责地点与冰雪节识别
- 大雪人：右侧，负责个人旅行记忆和视觉趣味

不要把三个地标叠在一起，也不要让摩天轮或冰塔遮住大雪人。

## 统一建模层级

建议每个场景都按下面的层级搭：

### A. 固定层

- Tesla Model Y 车内
- 驾驶员
- 方向盘
- 中控台
- 车内行李箱、纸张、乒乓球拍
- 前挡风玻璃边界

### B. 道路层

- 道路宽度
- 车道线
- 路肩
- 护栏
- 水面或雪面
- 车辆行驶方向

### C. 主地标层

每张图只设置一个绝对主地标，最多搭配两个辅助地标。

### D. 地域氛围层

- 植被
- 天气
- 建筑材料
- 地面材质
- 当地色彩
- 人群和交通

### E. 文字层

文字不要依赖模型自由生成，最好建模后单独做贴图或后期叠加：

- 地点路牌
- 名古屋的 `Aichi-Nagoya 2026`
- 其他必要地标文字

尤其是塔身竖向文字、路牌和建筑招牌，单独贴图会比生图稳定很多。
