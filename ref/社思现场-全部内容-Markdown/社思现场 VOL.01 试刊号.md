# 01. Clubhouse 上线“Topics”兴趣话题功能

> 参考链接：https://blog.clubhouse.com/topics-blog-post/

本次更新包含：

- Topic 可以被更精细化的词语搜索到，比如城市、大学、学术兴趣、音乐体裁等。
- 用户可选择感兴趣的话题，添加到个人资料页使用标签的形式展示。
- 在新的 Topic 页面中展示了热门搜索、Rooms、Clubs、话题相关 People 的推荐。
- 创建 Room 或 Room 开启后，可以添加 Topics 来告诉用户房间的话题。 未来预计会开放用户自己创建 Topics 的功能。

# 03. Telegram 更新 Reaction、Spoilers、消息翻译、主题二维码、更多的 Interactive Emoji

> 参考链接：https://telegram.org/blog/reactions-spoilers-translations

- Reaction：将动画 emoji 引入到“表态”功能，用户可以双击快速将自己设置的默认“表态”回复到消息。
- Spoilers：用户编辑选中文本并应用“扰乱”效果，被“扰乱”的文字发送后呈现为模糊的粒子形态，点击后可显示真正的文本内容。
- Translation：长按消息可选择翻译
- Themed QR Codes：用户可以为所有具有公开用户名的用户生成二维码，群、频道、机器人同样适用。二维码有多种颜色和样式可选。
- More Interactive Emoji：动画 emoji 新增： 🔥 😁🤩 😢😭 😱❄️。一对一聊天中发送可触发，点击已发送的 emoji 可触发全屏动画。

# 04. Discord 更新视频背景功能、服务器禁言功能

> 参考链接：https://twitter.com/discord/status/1462871539175419907?s=20

- 在视频通话时，可以设置模糊背景或将镜头中的背景替换为 Discord 预设背景。 Nitro 订阅用户可上传自定义视频背景。
- 新的服务器暂时禁言功能。服务器管理员现在可以暂时禁止用户互动，以遏制破坏性行为。 它也被称为“哟伙计你这样太烦人了闭嘴吧”按钮。
- 通过机器人的个人资料直接添加机器人。机器人开发人员可以在机器人的个人资料页面启用“添加至服务器”按钮，这样其他用户可以更方便地把它加入自己的服务器。

# 07. 小红书内测语音房「现场」功能

内测用户可从消息列表页顶部进入「现场」，加入或发起类似 Clubhouse 的语音房。

房间内可举手发言、向在麦用户发送私聊、点赞在麦用户、查看并关注用户。

房间列表中提供“预告”功能，供用户预约即将开启的房间，并一键加入到手机日历。

# 08. 抖音测试“通讯录”功能

> 参考链接：https://mp.weixin.qq.com/s/ILHQq-0ZLOgOIHZs89WS8Q?forceh5=1

抖音在底部第二个 Tab “朋友”中增加通讯录功能，和原有“好友视频动态”页并列为两个子 Tab。

通讯录上方优先排列最近访问的 3 名用户。朋友列表中整合了私信、设置备注名、设置是朋友还是关注关系、权限管理、移除/取关功能。

同时，通讯录顶部提供基于朋友关系的功能推荐区域，如：合唱、今日寿星、朋友在听、朋友在玩等。

# 09. 即刻推出会员计划，并上线个人主页“Yellow Page”功能

会员按照购买顺序发放唯一会员编号。

个人主页可选择模板生成专属链接，并链接社交媒体、作品、高光时刻、“友情链接”（即刻好友）。当前会员内容包括：

- Yellow Page：建立一页知你的专属页面。
- 身份标识：可选择展示会员标识。
- 个性图标：桌面图标支持更换。
- 特别关心：你关心的好友动向优先推送。
- 关键词过滤：屏蔽社区内不感兴趣内容。
- 动态编辑：可多次修改已经发布的动态。
- 评论权限：设置谁能评论你的动态。
- 资料修改：头像昵称7天就可更换。
